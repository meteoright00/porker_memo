# テスト計画テンプレート

機能追加・バグ修正時のTDDプランを構造化するテンプレート。

```
## テスト計画: [機能名/バグ名]

### テスト対象
- ファイル: ...
- 関数/コンポーネント: ...

### テストケース一覧

#### ユニットテスト
- [ ] **正常系**: ...
- [ ] **正常系**: ...
- [ ] **異常系**: ...
- [ ] **境界値**: ...
- [ ] **エッジケース**: ...

#### コンポーネントテスト
- [ ] **レンダリング**: 正しくレンダリングされること
- [ ] **ユーザー操作**: ボタンクリック時の動作
- [ ] **状態変化**: UIが状態変化に追従すること
- [ ] **バリデーション**: 不正入力時のエラー表示

### テストダブル
- モック対象: ...
- スタブ対象: ...
- fake-indexeddb の使用: Yes / No

### テスト実行コマンド
npm test -- --reporter=verbose [テストファイルパス]
```
