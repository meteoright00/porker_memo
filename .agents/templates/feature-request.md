# 機能追加依頼テンプレート

以下の情報を記入して `/add-feature` ワークフローに渡してください。

```
## 機能追加依頼

### 機能名
（例: ハンド表示の詳細フィルタリング機能）

### 対象画面
（例: ハンド履歴一覧ページ, 新規ページ）

### ユーザーストーリー
（ポーカープレイヤー）として、
（特定のポジションでの勝率を時系列で確認）したい。
なぜなら（自分のポジション別のプレイ精度を改善したい）から。

### 受け入れ条件
- [ ] ...
- [ ] ...
- [ ] ...

### 優先度
（高 / 中 / 低）

### 参考（任意）
（似たアプリの画面、デザインイメージなど）
```

## 使用例

```
/add-feature
## 機能追加依頼
### 機能名
ハンド記録のポジション別統計
### 対象画面
新規ページ（トップページからリンク）
### ユーザーストーリー
ポーカープレイヤーとして、
ポジション別の勝率・アクション傾向を確認したい。
なぜなら弱いポジションのプレイを改善したいから。
### 受け入れ条件
- [ ] 各ポジション(SB,BB,UTG,MP,CO,BTN)ごとの勝率が表示される
- [ ] 各ポジションごとのハンド数が表示される
- [ ] 期間でフィルタリングできる
### 優先度
中
```
