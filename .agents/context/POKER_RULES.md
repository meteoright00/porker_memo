## 1. ゲームの基本構造

テキサスホールデムは、2枚のホールカード（自分だけが見えるカード）と最大5枚のコミュニティカード（ボード）を使い、最良の5枚の組み合わせを競うポーカーゲーム。

### 1.1 カードの表記

- **ランク**: 2, 3, 4, 5, 6, 7, 8, 9, T(10), J, Q, K, A
- **スート**: s(スペード♠), h(ハート♥), d(ダイヤ♦), c(クラブ♣)
- **表記例**: `As`(スペードのA), `Kh`(ハートのK), `Td`(ダイヤの10)
- **ハンド表記**: `AKs`(同スート), `AKo`(異スート), `AA`(ペア)

### 1.2 デッキ

- 52枚 (13ランク × 4スート)
- ジョーカーなし

---

## 2. ストリート（フェーズ）

ゲームは4つのストリート（ベッティングラウンド）で進行する。

| ストリート | ボード枚数 | 説明 |
|---|---|---|
| **Preflop** | 0枚 | ホールカード配布後、最初のベッティングラウンド |
| **Flop** | 3枚 | 3枚のコミュニティカードが同時にオープン |
| **Turn** | 4枚 (1枚追加) | 4枚目のコミュニティカードがオープン |
| **River** | 5枚 (1枚追加) | 5枚目（最後）のコミュニティカードがオープン |

### 2.1 進行ルール

- 各ストリートでベッティングアクションが行われる
- あるストリートで全員のアクションが完了（コール or チェック回り）したら次のストリートへ進む
- いずれかのストリートで1人を除く全員がフォールドした場合、残った1人がポットを獲得しハンド終了
- Riverまで到達し、複数人が残っている場合はショーダウン（手を見せ合い）で勝者決定

---

## 3. ポジション

### 3.1 ポジション定義

ポジションはテーブルの人数によって変わる。

**2-max (ヘッズアップ):**
`SB`, `BB`

**6-max:**
`SB`, `BB`, `UTG`, `MP`, `CO`, `BTN`

**9-max:**
`SB`, `BB`, `UTG`, `EP`, `MP`, `LJ`, `HJ`, `CO`, `BTN`

**10-max:**
`SB`, `BB`, `UTG`, `UTG+1`, `EP`, `MP`, `LJ`, `HJ`, `CO`, `BTN`

### 3.2 ポジションの略称

| 略称 | 正式名 | 説明 |
|---|---|---|
| SB | Small Blind | 強制ベット（小）を出すポジション |
| BB | Big Blind | 強制ベット（大）を出すポジション |
| UTG | Under The Gun | BB の左隣。Preflopで最初にアクション |
| EP | Early Position | 序盤ポジション |
| MP | Middle Position | 中盤ポジション |
| LJ | Lojack | HJの右隣 |
| HJ | Hijack | COの右隣 |
| CO | Cutoff | BTNの右隣 |
| BTN | Button (Dealer) | ディーラーボタン。Postflopで最後にアクション |

### 3.3 アクション順序

**Preflop（ブラインドが強制ベット済み）:**
`UTG → EP → MP → LJ → HJ → CO → BTN → SB → BB`

**Postflop（Flop, Turn, River）:**
`SB → BB → UTG → EP → MP → LJ → HJ → CO → BTN`

> **実装上の注意**: `src/utils/pokerLogic.ts` の `getNextActor()` / `getInitialActor()` で上記順序を実装している。Preflopではブラインド(SB,BB)を配列末尾に移動する方式。

## 4. アクション

| アクション | 説明 | 使用条件 |
|---|---|---|
| **Fold** | ハンドを降りる。以降参加不可 | いつでも可能 |
| **Check** | ベットせず次へ回す | 自分の前にベットがない場合のみ |
| **Call** | 直前のベット/レイズと同額を出す | ベットが存在する場合 |
| **Bet** | そのストリートで最初の賭け金を出す | 自分の前にベットがない場合 |
| **Raise** | 直前のベットを上回る額を出す | ベットが存在する場合 |
| **All-in** | 手持ちチップ全額を賭ける | いつでも可能 |

### 4.1 ブラインド (強制ベット)

- **SB (Small Blind)**: BBの半額を強制的にベット
- **BB (Big Blind)**: 所定額を強制的にベット
- **Ante**: 全員が出す強制ベット（トーナメントで使用）
  - 「Ante = BB」: Anteの額がBBと同額になる特殊ルール（大会でよく採用）

## 5. トーナメント固有の概念

### 5.1 ブラインドストラクチャー

- トーナメントではブラインドが時間経過とともに上昇する
- 各レベルは `SB / BB / Ante / 時間(分)` で定義される
- ブレイク（休憩）レベルも存在する

### 5.2 M値 (M-value)

プレイヤーの持ちチップの余裕度を示す指標。

```
M = スタック / (SB + BB + Ante × 参加人数)
```

| M値 | ゾーン | 戦略 |
|---|---|---|
| 20以上 | グリーン | 通常プレイ |
| 10〜20 | イエロー | やや制限されたプレイ |
| 5〜10 | オレンジ | ショートスタック戦略 |
| 1〜5 | レッド | プッシュ or フォールド |
| 1未満 | デッド | 即座にオールイン |

### 5.3 トーナメントステータス

| ステータス | 説明 |
|---|---|
| `pending` | 登録済み・開始待ち |
| `active` | プレイ中 |
| `completed` | 終了済み（順位・参加者数を記録） |

## 6. 自動タグ付けルール

本アプリでは、アクション系列から以下のタグを自動生成する（`src/utils/tagUtils.ts`）。

### 6.1 ポットサイズ系タグ

Preflop のレイズ回数で決定:

| レイズ回数 | タグ |
|---|---|
| 1回 | `Single Raised Pot` (SRP) |
| 2回 | `3Bet Pot` |
| 3回以上 | `4Bet Pot` |

> **注意**: "3Bet" は3回目のベットではなく、レイズに対するリレイズを指す。Preflopの最初のレイズがオープンレイズ (2-bet)、それに対するレイズが 3-bet。

### 6.2 アグレッション系タグ (Flop)

| タグ | 条件 |
|---|---|
| `C-Bet` | Preflop アグレッサーが Hero → Flopで Hero が最初に Bet |
| `Donk Bet` | Preflop アグレッサーが Villain → Flopで Hero が最初に Bet |
| `Check-Raise` | Flopで Hero が Check → Villain が Bet → Hero が Raise |

### 6.3 判定ロジックの注意点

- **C-Bet 判定**: Heroの前にBet/Raiseがないこと（=Heroが最初のベッター）が必須
- **Donk Bet 判定**: Preflop アグレッサーがVillainであること + Heroが最初のベッター
- **Check-Raise 判定**: Check → 相手Bet → Raise の3段階パターンマッチ
- **lastAggressor**: Preflopで最後に Bet/Raise/All-in したプレイヤー (Hero or Villain)

---

## 7. ハンド終了条件

ハンドは以下の条件で終了する（`src/utils/pokerLogic.ts` の `checkHandEnded()`）:

1. **Hero がフォールド**: 即座にハンド終了
2. **全Villain がフォールド**: Hero以外の全員がフォールド → Hero勝利でハンド終了
3. **Riverまで到達**: ショーダウンで勝敗決定

---

## 8. 勝敗判定

| 結果 | 説明 |
|---|---|
| `Win` | Hero がポットを獲得 |
| `Lose` | Hero がポットを失う |
| `Chop` | ポットを分割 |
