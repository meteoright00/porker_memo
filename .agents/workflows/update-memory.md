# メモリ更新ワークフロー

## 推奨モデル
| 常に | 推奨モデル |
|---|---|
| — | **Gemini 3 Flash** または **Gemini 3.1 Pro (Low)** |

## 概要
本日（または直近のセッション）の作業内容を要約し、次回や今後別のAIがタスクを引き継ぐための情報を `.agents/context/PROJECT_MEMORY.md` に更新する。

## ワークフロー

### Step 1: コンテキストの収集
現在の会話履歴、直近で変更されたファイル、およびコミットされていない変更内容を読み取り、以下の情報を整理する:
1. **Recent Accomplishments**: 直近で完了したタスク・実装した機能
2. **Current Context**: 途中になっているコードや進行中の議論
3. **Next Steps**: 次回着手すべきタスク、残っている課題

### Step 2: メモリの更新
`.agents/context/PROJECT_MEMORY.md` を読み込み、Step 1 で整理した情報を基に中身を更新する。
- `Last Active` を今日の日付に更新する
- 古くなった `WIP` や `Next Steps` は `Recent Accomplishments` に移動するか削除する
- `User Preferences & Rules` に追加すべき新しい気付きがあれば追記する

### Step 3: 更新の報告
```
## メモリ更新完了
プロジェクトメモリに以下の引き継ぎ事項を記録しました:
- 完了したこと: ...
- 次回やること: ...
```
