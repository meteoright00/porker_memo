# 品質チェックリスト

> AIエージェントが変更を完了する前に必ず確認すべき品質ゲート。
> すべてのワークフロー（fix-bug, add-feature, refactor）で最終確認として使用する。

---

## コード品質

- [ ] **TypeScript 厳格性**: `any` 型を使用していない
- [ ] **関数の型注釈**: すべての関数・Propsに明示的な型アノテーションがある
- [ ] **Zodスキーマ**: 新規データモデルはZodスキーマで定義し、型推論を利用している
- [ ] **Functional Component**: Class Componentは使用していない（Hooks のみ）
- [ ] **純粋関数**: 副作用を最小限に抑え、ロジックは純粋関数で実装している
- [ ] **命名規則**:
  - コンポーネント: `PascalCase`
  - 関数・変数: `camelCase`
  - 定数: `UPPER_SNAKE_CASE`

## テスト

- [ ] **新規テスト追加**: 新規ロジックにユニットテストを追加済み
- [ ] **テスト全パス**: `npm test` が全テスト通過
- [ ] **ビルド成功**: `npm run build` が成功
- [ ] **回帰なし**: 既存テストに回帰的失敗がない
- [ ] **エッジケース**: 境界値・異常系のテストがある

## UI/UX (モバイルファースト)

- [ ] **タップ領域**: ボタン・リンクのタップ領域は 48px 以上
- [ ] **レスポンシブ**: モバイル幅(375px〜)で正常に表示される
- [ ] **Tailwind CSS**: スタイリングはTailwind CSSで定義（インラインスタイル非推奨）

## オフラインファースト

- [ ] **サーバー通信なし**: fetch / axios 等の外部通信を行っていない
- [ ] **Dexie.js**: データの永続化はDexie.js (IndexedDB) で行っている
- [ ] **エラーハンドリング**: DB操作にはtry-catchを適用し、ユーザーへ通知している

## ドキュメント鮮度（必須）

- [ ] **CODEBASE_MAP.md**: ファイル追加/削除/移動があった場合は更新済み
- [ ] **ARCHITECTURE.md**: アーキテクチャ変更があった場合は更新済み
- [ ] **POKER_RULES.md**: ドメインロジック変更があった場合は更新済み
- [ ] **README.md**: ユーザー向け機能変更があった場合は更新済み
