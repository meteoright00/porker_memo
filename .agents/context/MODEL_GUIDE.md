# AIモデル選択ガイド

> 各ワークフローで使用する推奨モデル。コスト効率と品質のバランスを最適化する。
>
> **最終更新**: 2026-04-05

---

## 利用可能モデル

| モデル | コスト | 得意領域 |
|---|---|---|
| **Claude Opus 4.6 (Thinking)** | 💰💰💰💰💰 | 複雑な要件定義、高度な設計判断、重大バグの根本原因分析 |
| **Claude Sonnet 4.6 (Thinking)** | 💰💰💰 | 要件定義、コードレビュー、中〜高複雑度の分析 |
| **Gemini 3.1 Pro (High)** | 💰💰💰 | 大規模コーディング、複雑な実装、アーキテクチャ変更 |
| **Gemini 3.1 Pro (Low)** | 💰💰 | 標準的なコーディング、小〜中規模の変更 |
| **Gemini 3 Flash** | 💰 | 定型作業、ドキュメント更新、単純な修正 |

## ワークフロー別推奨モデル

### `/fix-bug` — バグ修正

| バグの深刻度 | 推奨モデル | 理由 |
|---|---|---|
| **軽微** (UI崩れ、typo等) | Gemini 3 Flash | 原因が明白、修正も軽量 |
| **中程度** (機能不具合) | Gemini 3.1 Pro (Low) | 標準的なデバッグ・修正 |
| **重大** (データ不整合、ロジックバグ) | Gemini 3.1 Pro (High) | 根本原因分析に強い推論力が必要 |
| **致命的** (原因不明、再現困難) | Claude Sonnet 4.6 | Thinkingモードで段階的な推論が有効 |

### `/add-feature` — 機能追加

| 機能の規模 | 推奨モデル | 理由 |
|---|---|---|
| **小** (1-2ファイル変更) | Gemini 3.1 Pro (Low) | 十分な品質でコスト最適 |
| **中** (3-5ファイル、新規コンポーネント) | Gemini 3.1 Pro (High) | アーキテクチャ理解が必要 |
| **大** (新ページ、データモデル変更) | Gemini 3.1 Pro (High) | 複数レイヤーにまたがる実装 |

### `/make-requirements` — 要件定義

| 要件の複雑度 | 推奨モデル | 理由 |
|---|---|---|
| **標準** | Claude Sonnet 4.6 | 1問1答の対話型思考に最適 |
| **複雑** (新概念、大規模設計) | Claude Opus 4.6 | 深い洞察と構造化能力が必要 |
| **Claudeが使えない時** | Gemini 3.1 Pro (High) | 代替として十分な品質を提供 |

### `/code-review` — コードレビュー

| レビュー対象 | 推奨モデル | 理由 |
|---|---|---|
| **小規模変更** | Gemini 3.1 Pro (Low) | チェックリスト準拠の定型レビュー |
| **大規模/重要変更** | Claude Sonnet 4.6 | 設計判断の妥当性評価に強い |

### `/refactor` — リファクタリング

| リファクタの規模 | 推奨モデル | 理由 |
|---|---|---|
| **単一ファイル** | Gemini 3.1 Pro (Low) | コード変換は標準モデルで十分 |
| **複数ファイル横断** | Gemini 3.1 Pro (High) | 依存関係の理解が必要 |

### `/sync-docs` — ドキュメント同期

| 常に | 推奨モデル | 理由 |
|---|---|---|
| — | **Gemini 3 Flash** | 定型的なスキャン・比較・更新作業。推論力は不要 |

---

## コスト最適化のコツ

1. **まずFlashで試す**: 単純な作業は Flash で十分なことが多い
2. **Opusは最終手段**: 要件定義の重要な局面でのみ使用する
3. **Sonnetは分析向き**: コードを書くよりも、レビュー・要件定義に使う
4. **Pro (High) が主力**: 日常的なコーディングの主力モデル
5. **Pro (Low) がデフォルト**: 迷ったらまず Pro (Low) で始め、不足を感じたら上げる

## 日常の使い分けサマリー

```
日常作業 → Gemini 3.1 Pro (Low) or Flash
コーディング → Gemini 3.1 Pro (High)
要件定義 → Claude Sonnet 4.6
重要な設計判断 → Claude Opus 4.6（月に数回程度に抑える）
ドキュメント更新 → Gemini 3 Flash
```
