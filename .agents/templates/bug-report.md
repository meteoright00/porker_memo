# バグ報告テンプレート

以下の情報を記入して `/fix-bug` ワークフローに渡してください。

```
## バグ報告

### 画面
（例: トーナメント詳細ページ, ハンド記録ウィザード）

### 再現手順
1. ...
2. ...
3. ...

### 期待する動作
（例: チップが記録され、一覧に表示される）

### 実際の動作
（例: ボタンを押しても何も起きない / エラーが表示される）

### エラーメッセージ（あれば）
（コンソールエラー、画面上のエラーメッセージなど）

### ブラウザ / 端末（任意）
（例: iPhone Safari, Chrome Android）

### スクリーンショット（任意）
（画面キャプチャがあれば添付）
```

## 使用例

```
/fix-bug
## バグ報告
### 画面
ハンド記録ウィザード - アクション入力画面
### 再現手順
1. ポジション選択でBTNを選択
2. ホールカードを選択
3. Preflopアクションで「Raise」を選択
### 期待する動作
レイズ額の入力欄が表示される
### 実際の動作
画面が固まり、操作できなくなる
```
